# 短期工作材料

本目录用于需要纳入版本管理、供协作者共同审阅的短期材料，例如尚待决策的设计提案、方案比较或阶段验证说明。无需保留的任务报告不应为了填充目录而创建。

## 材料入口

- [下一代交互预览](ui-next-preview.html)：可离线打开的完整设计提案；[源码与范围说明](ui-next-preview/README.md) 标明主分支对齐基线、演示边界及清理条件。

- [运行时发布前待核事项](runtime-release-readiness.md)：从旧任务清单筛出的待核问题，区分源码、已有构建记录和仍缺少的验收证据。
- [运行时选型调研复核](runtime-research-recheck.md)：核对仍有效的 Android 机制，标明旧竞品比较和候选后端的证据边界。

以上材料均有明确核对日期和清理条件，不作为项目长期规范或实时状态看板。

每份材料至少说明适用范围、依据或验证条件、尚待决定的问题，以及何时可以删除或提炼为长期文档。材料可以注明所依据的版本或日期，但不能据此宣称整个项目的当前状态。

结论确定后，将长期有效的规则或规划合并到对应主题文档；其余内容按协作需要删除。这里不维护持续增长的已完成任务清单。

凭据、用户数据、本机路径配置、原始日志和批量截图不进入本目录。临时输出使用根级 `temp/`，自动化记录优先链接到 CI 或发布附件。
