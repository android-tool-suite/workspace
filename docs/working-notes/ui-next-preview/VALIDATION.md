# 预览验证边界与审阅条件

核对日期：2026-09-20。第六轮同步外层主分支 `26f1069`，补齐账号选择保存和获取边界。本文只对应独立 HTML；所有账号、文件和业务记录均为合成样例。

## 本轮验证

通过浏览器实际操作本地开发服务中的生成文件，并使用预览内的 `requestAnimationFrame` 采样记录 DOM 状态和计算后透明度。未读取浏览器外的真实业务数据。

| 范围 | 观察结果 |
| --- | --- |
| 保存阶段时序 | 分别以 80 / 190 / 210 / 1200 ms 检查；快速和临界完成时本次没有采样到提示，慢保存正常显示进度。所有情境中账号与正文没有部分切换或空白刷新 |
| 账号选择保存 | 目标记录已就绪而保存仍等待时，切到记录页仍显示原账号 848 条；保存成功后一起切成原神 520 条。失败后保留原账号与自定义分析设置，重试成功才切换 |
| 取消与冲突操作 | 模拟冷启动取消未完成保存，重新打开仍为原账号；保存期间禁用冲突写入，浏览与切页继续可用，完成后恢复操作 |
| 数据读取汇总 | 一个游戏失败而另一个仍在读取时，保留外壳；全部结束后显示原神 520 条及星铁单独错误，正常账号可直接打开 |
| 设备日志 | 默认系统保留的全部范围，包含 24 小时选项；明确不支持浏览器云游戏，没有此类网页入口 |
| 失败隔离 | 星铁首次读取失败后，可直接切换到原神并浏览 520 条记录，不受全局失败状态阻挡 |
| 全场景巡检 | 77 个场景无横向溢出、异常占位值或页面脚本错误；有意停留的读取仅显示稳定外壳和既有反馈 |
| 推分及页面保留 | 推分完成后展开项与滚动值保持不变；图片生成等待结果就绪。页面往返保留搜索和筛选展开状态，模拟冷启动回到总览 |
| 宽屏 | 960 × 720 检查保存失败、数据页及日志获取三个场景，无正文横向溢出 |
| 小屏深色 | 360 × 800 检查 6 个相关页面，标题、上下文、正文及底栏无横向溢出 |

计时数值包含浏览器调度和渲染，随机器负载变化；它们描述本次模拟条件下的结果，不是真机耗时。帧采样在浏览器绘制前读取 DOM / CSS，不能替代真实屏幕录屏。临界情况下允许既有提示短暂处于渐入的极低透明度，不以此为理由新增临时文案、摘要或等待页。

## 范围与限制

仅修改外层独立预览及说明，六个子模块仍未检出。本轮已同步主分支，未修改 Android 源码、提升产品版本、构建 APK / 插件包或执行模拟器 / 真机测试。

浏览器测试通过回环开发服务加载同一份文件；没有用文件管理器双击 HTML。单文件独立性通过资源全部内嵌和无网络依赖检查核对。

真实登录、系统授权、备份加密恢复、存档解析、RKS / 保底算法以及文件下载落盘均不属于本轮验证。预览的账号与业务变化只作用于当前浏览器会话。
