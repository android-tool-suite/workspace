### 发现与修复

发现软键盘收起后数据操作弹窗保持缩小并居中的问题。旧的可见区域计算受弹窗自身尺寸影响，无法恢复完整高度；直接读取浮动弹窗的 IME inset 也无法正确避让键盘。

现在 Android 11 及以上从 Activity 的 `currentWindowMetrics` 获取键盘遮挡高度，并以稳定的宿主窗口范围计算可用高度；旧系统仍使用窗口 inset。窗口差异的分析参考了本地 Compose 1.7.7 产物和 [AndroidX Dialog 实现](https://android.googlesource.com/platform/frameworks/support/+/521b662e466e9b88af2598468f369163ce265adb/compose/ui/ui/src/androidMain/kotlin/androidx/compose/ui/window/AndroidDialog.android.kt)。本轮修复仅改动宿主实现，更新主体日志和设计规范，沿用当前尚未提交的版本号。

真机上重复两次键盘弹出／收起：标题保持在 y=229–331；操作按钮从 y=2983–3053 上移到 y=1810–1880，收起后恢复原位置。键盘上方的按钮可见可用。更新后的模拟器也重新确认底栏完整显示。
